# Building Lifecycle Ontologies Working Group

The goal of this working group is to survey, collect, develop and support data ontologies for the lifecycle of buildings, to facilitate quicker and better software development for the real estate and building industry.

## Governance
As described this project's [Governance.md](docs/Governance.md) file, Working Group decisions are made by consensus of the Working Group Participants. To become a Working Group Participant, please make a contribution and open a pull request to add your name below.
