# Contributing Demos
The Working Group would like to develop and maintain a collection of demos in order to show, rather than tell, the benefits of semantic interoperability. Ideal demos showcase great developer experiences interoperability between traditionally isolated platforms/protocols, low-friction implementation, adoption, or migration paths, and/or application-specific use cases. Demos can also highlight gaps that could be filled by new open source tooling, plugins, or spec additions.

**If you would like to develop and contribute a demo to the Working Group,** please do the following...
* Copy and update the Demo Explainer Template
* {Q: do we want all demos in our org?}
* Add your demo to the list below
